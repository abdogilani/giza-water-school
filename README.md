# مدرسة مياه الشرب والصرف الصحي بالجيزة — حزمة الموقع

## ملفات المشروع
- `index.html`: الموقع العام، مع الحفاظ على التصميم الأصلي (RTL والألوان والأقسام).
- `login.html`: تسجيل دخول حساب الإدارة بالبريد وكلمة المرور.
- `admin.html`: إضافة الإنجازات وتعديلها وحذفها، ونشرها أو حفظها كمسودة.
- `js/config.js`: عنوان مشروع Supabase ومفتاح النشر العام فقط.
- `supabase/schema.sql`: نسخة مراجعة من بنية الجداول وسياسات RLS والـ triggers الحالية.
- `SECURITY-REVIEW.md`: نتائج المراجعة الأمنية والاختبارات وحدود ما تم التحقق منه.

## تشغيل ونشر الموقع
هذه حزمة موقع Static وليست تطبيقًا يحتاج إلى بناء محلي:
1. فك ضغط الملف.
2. ارفع **كل محتويات مجلد** `school-supabase-project` إلى استضافة مواقع ثابتة تدعم HTTPS.
3. حافظ على نفس ترتيب المجلدات، خصوصًا `js/config.js` و`supabase/schema.sql`.
4. اجعل `index.html` صفحة البداية.
5. أضف نطاق الموقع النهائي إلى إعدادات Supabase Authentication → URL Configuration ضمن Site URL وRedirect URLs عند الحاجة.
6. في Supabase → Project Settings / Integrations → Data API تأكد أن `public` ضمن Exposed schemas. لا يمكن تأكيد هذا الإعداد من ملفات المشروع وحدها.

## اختبار بعد النشر
- افتح الموقع كزائر: يجب أن تظهر الإنجازات المنشورة فقط.
- افتح `login.html` وسجل الدخول بحساب الإدارة.
- جرّب إنشاء إنجاز تجريبي غير منشور، ثم نشره، وتعديله، وحذفه.
- افتح الموقع في نافذة خاصة وتأكد أن المسودة لا تظهر للزوار.
- جرّب حسابًا عاديًا غير إداري (إن توفر) وتأكد أنه لا يستطيع فتح لوحة الإدارة أو تعديل البيانات.

## تنبيه بخصوص المحتوى
يوجد حاليًا سجلان ابتدائيان للإنجازات نُقلا من محتوى HTML المقدم. لم يتم التحقق بشكل مستقل من صحة وقوع هذه الأحداث؛ راجع المدرسة واستبدلهما أو أزل نشرهما إذا لم يكونا صحيحين. تم الحفاظ على نصوص القبول والتوظيف والأقسام كما كانت في الملف الأصلي ولم يتم توثيقها خارجيًا.

## ملاحظة مهمة
قاعدة البيانات وربط الواجهة بالـ API وصفحات الدخول والإدارة جاهزة داخل الحزمة، لكن **الموقع لم يُنشر على الإنترنت بعد**. لا يمكن اعتبار تسجيل الدخول وعمليات CRUD قد اجتازت اختبار متصفح حي حتى يتم رفع الملفات على الاستضافة واختبارها من عنوان HTTPS الفعلي.
