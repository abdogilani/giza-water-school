# موقع مدرسة مياه الشرب والصرف الصحي بالجيزة

## النشر على GitHub Pages
1. أنشئ مستودع GitHub جديدًا (يفضل Public إذا كنت تريد رابطًا عامًا).
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يكون `index.html` في الجذر مباشرة.
3. من Settings → Pages اختر Deploy from a branch، ثم `main` و`/ (root)` واضغط Save.
4. انتظر اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## صفحات المشروع
- `index.html`: الموقع العام.
- `login.html`: تسجيل دخول الإدارة.
- `admin.html`: لوحة إدارة الإنجازات.
- `js/config.js`: إعداد اتصال Supabase (رابط المشروع ومفتاح Publishable عام).
- `supabase/schema.sql`: توثيق مخطط قاعدة البيانات وسياسات الحماية.

## ربط Supabase
المشروع يستخدم Supabase الموجود في `js/config.js`. المفتاح الموجود هناك هو Publishable Key مخصص للاستخدام في المتصفح، مع ضرورة استمرار تفعيل RLS. لا تضع أبدًا `service_role` أو `sb_secret` أو كلمات المرور في ملفات الموقع أو GitHub.

بعد اختيار رابط GitHub Pages:
- افتح Supabase → Authentication → URL Configuration.
- أضف رابط GitHub Pages إلى Site URL وRedirect URLs عند الحاجة.
- تحقق من إعداد Data API وأن `public` ضمن Exposed schemas.
- اختبر تسجيل دخول حساب الإدارة وإضافة/تعديل/حذف إنجاز تجريبي.

## تنبيهات قبل الإطلاق
- شروط القبول والتوظيف والأرقام المكتوبة بالموقع محتوى من الملف الأصلي ولم يتم التحقق منها من مصدر رسمي؛ يجب مراجعتها واعتمادها من إدارة المدرسة قبل النشر.
- راجع سجلات الإنجازات الحالية في Supabase وتأكد أنها أحداث حقيقية قبل إبقائها منشورة.
- فعّل حماية كلمات المرور المسرّبة من إعدادات Supabase Auth → Password Security.
- GitHub Pages يستضيف الواجهة الثابتة فقط؛ بيانات الإنجازات وتسجيل الدخول تظل على Supabase.

## اختبار محلي
افتح `index.html` مباشرة للمعاينة. لاختبار تسجيل الدخول وعمليات Supabase يفضل تشغيل المشروع عبر خادم محلي أو HTTPS.
